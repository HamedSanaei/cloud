# سیاست ورود پارس سرور

## ورود یک‌مرحله‌ای (فعال)

در نسخه فعلی، **مرحله دوم احراز هویت هنگام ورود برای تمام حساب‌ها، شامل مدیران و کاربران عادی، غیرفعال است**.

- ورود با ایمیل و رمز عبور معتبر مستقیماً یک نشست ایجاد می‌کند؛ OTP ایمیلی یا TOTP خواسته نمی‌شود.
- برای حساب‌هایی که قبلاً TOTP فعال داشته‌اند نیز مرحله دوم اجرا نمی‌شود؛ حالت مؤثر آن‌ها در API غیرفعال گزارش می‌شود.
- راه‌اندازی یا فعال‌سازی مجدد TOTP از API و تنظیمات حساب غیرفعال است. تنظیمات و کلیدهای تاریخی TOTP بدون مهاجرت تخریبی در پایگاه داده باقی می‌مانند، ولی در این حالت اجرا نمی‌شوند.
- ورود با گوگل طبق اعتبارسنجی خود ارائه‌دهنده انجام می‌شود و در سایت مرحله دوم اضافه نمی‌شود.

**تمایز مهم:** ورود صرفاً با شماره موبایل و بدون رمز عبور، همچنان برای اثبات مالکیت شماره به یک پیامک OTP نیاز دارد. این پیامک *عامل اولیه* ورود محسوب می‌شود، نه مرحله دوم. حذف آن بدون افزودن رمز عبور یا روش احراز هویت جایگزین، ورود به حساب دیگران را ممکن می‌کند.

## مواردی که همچنان تأیید لازم دارند

تأیید ایمیل یا موبایل هنگام **ثبت‌نام** و ارسال کد ایمیلی برای **بازیابی رمز عبور** حذف نشده‌اند. محدودیت دفعات تلاش و ارسال مجدد کد نیز برقرار است. مجوز دسترسی مدیران در بک‌اند جداگانه بررسی می‌شود.

## پیکربندی

```env
AUTH_LOGIN_SECOND_FACTOR_ENABLED=false
```

مقدار پیش‌فرض `false` است و نیازی به تغییر متغیرهای محیطی استقرار فعلی نیست. روشن‌کردن عمدی این متغیر در آینده، سیاست قبلی OTP ایمیلی یا TOTP ورود را برمی‌گرداند و باید تنها پس از بازگرداندن کامل رابط کاربری و تست‌های مربوط انجام شود.

پس از انتشار تغییرات، از صفحه تأیید قدیمی خارج شوید و ورود جدید را از `/login` یا `/admin` آغاز کنید. کدهای یک‌بارمصرف ثبت‌نام و بازیابی رمز همچنان معتبرند.
